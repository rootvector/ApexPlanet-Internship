# Task 4 – Exploitation & System Security

**Internship:** ApexPlanet Cybersecurity & Ethical Hacking  
**Task:** 4  
**Duration:** Days 37–48  
**Focus:** Exploitation, Password Security, Social Engineering Awareness, Malware Analysis and System Hardening.

## Objective

To understand the penetration-testing workflow, identify and exploit known vulnerabilities in an authorized lab environment, analyze password security, study malware behavior, and implement basic system-hardening measures.

## Topics Covered

### 1. Penetration Testing Methodology
- Reconnaissance
- Scanning and Enumeration
- Vulnerability Identification
- Exploitation
- Post-Exploitation
- Reporting

### 2. Exploitation with Metasploit
- Introduction to the Metasploit Framework.
- Understanding known vulnerabilities.
- Exploitation of a vulnerable lab machine.
- Reverse shell concepts.
- Post-exploitation and system information gathering.

### 3. Password Security
- SSH authentication testing using Hydra in an authorized lab.
- Password hash identification.
- Password auditing using John the Ripper.
- Understanding password strength and secure storage.

### 4. Phishing Awareness
- Understanding phishing techniques.
- Creating a local phishing-awareness simulation.
- Identifying suspicious links and forms.
- Learning preventive security practices.

### 5. Malware Analysis
- Introduction to static analysis.
- Introduction to dynamic analysis.
- Analysis of a benign sample in an isolated environment.
- Understanding indicators of suspicious behavior.

### 6. System Hardening
- Applying security updates.
- Configuring firewall rules.
- Reviewing running services.
- Disabling unnecessary services.
- Following the principle of least privilege.

## Tools Used

- Kali Linux
- Metasploit Framework
- Hydra
- John the Ripper
- Linux utilities
- Apache / local web server
- Isolated virtual machines

## Testing Scope

All practical security testing is intended for personally controlled virtual machines and authorized laboratory environments.

## Security Considerations

- Obtain authorization before testing.
- Avoid testing third-party systems.
- Use isolated environments for exploitation and malware analysis.
- Never use real credentials or personal data in demonstrations.

## Conclusion

Task 4 covers practical penetration-testing concepts and system-security practices. It demonstrates the importance of identifying vulnerabilities, understanding exploitation techniques, auditing password security, recognizing social-engineering threats, analyzing suspicious files, and implementing system-hardening controls.
